# Designs

Each design document covers one or more parts of the [roadmap](../ROADMAP.md). Its sections are written and reviewed
one at a time; each has a status: *proposed*, *approved* (with the date), or *revised after approval* (with what
changed and why, also listed in the document's revision log). Only approved sections are built. When every section is
approved, the document is self-reviewed, the owner reads it whole, and implementation plans follow
([docs/plans/](../plans/README.md)).
