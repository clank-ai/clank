# M1.2: hosts, and the processes Clank starts on them: implementation plan

> As for M1.1, this plan gives the files, interfaces and tests by name and intent; the code is in the commits, written
> test-first.

**Goal:** the host kind of adapter (decision 0030): a `local` host and a `wsl` host that start an engine in a session of
its own with its output in a log, identify it (process id, start time, command line), tell whether it still runs, and
stop it only when it is still the process Clank started; plus what a check needs to know about a file there (does it
exist, its size, its SHA-256) and who listens on a port. A fake engine that starts, answers and stops like KVMem or
NInfer, for M1.3's tests.

**Architecture:** design 0003 §2. `EngineHost` is an `Adapter` of the new kind `host`. The `local` host runs processes
on the service's own machine through Python (`subprocess` to start them, `psutil` to identify them), on any operating
system, so the runtime's tests run on Windows and on Linux CI with fake engines. The `wsl` host runs everything inside a
distribution through `wsl.exe -d <distro> -e bash -c <script>`, identifying a process by its `/proc` entries. A
`ProcessIdentity` is the host's name, the process id, its start time as the host reports it, and the SHA-256 of its
command line; every signal is sent by a script that checks all three first.

**Tech Stack:** what M1.1 uses; `psutil` (decision 0025) for the local host.

**Spec:** [design 0003](../design/0003-the-runtime.md) §2, §6.3, §9; design 0001 §4.6; decision 0030.

## Global Constraints

- Everything of M1.1's global constraints holds.
- Clank signals a process only when its identity matches all three parts; a process that is gone, or whose id was
  reused, is never signaled.
- A started process outlives the call that started it and the service (its own session, its input from nowhere).

## Review Focus

1. **A process id reused by another program after the engine ended:** not alive, and never stopped. Pinned in Task 1.
2. **A process that ignores the polite stop:** ended after its time is up, and said so. Pinned in Task 1.
3. **A started process whose command line is not yet its own** (the moment between `setsid` and the engine's `exec`):
   its identity is taken once the command line is the engine's. Pinned in Task 2.
4. **A program the host cannot start** (missing, not executable): said with the host's own words, no identity. Pinned
   in Tasks 1 and 2.
5. **WSL's answers in UTF-16** (`wsl.exe --list`): read as text. Pinned in Task 2.

### Task 1: The host kind and the local host

**Files:** `clank/components/runtime/hosts/{__init__,host,local}.py`; `clank/kernel/adapters.py` (an adapter whose
program is the running system itself is not recorded: `RECORDED`); `tests/test_architecture.py`; tests
`tests/components/runtime/test_local_host.py`, `tests/contract/test_host.py`.

**Interfaces:** `ProcessIdentity` (host, pid, started, command), `HostError`, `EngineHost` (`spawn(argv, env, cwd, log)
-> ProcessIdentity`, `alive(identity) -> bool`, `stop(identity, seconds) -> Stopped` (`"stopped"`, `"killed"`,
`"gone"`), `exists(path)`, `size(path)`, `sha256(path)`, `expand(path)`, `listener(port) -> str | None`), the kind
`HOSTS`; `LocalHost`.

**Tests:** a started process runs in a session of its own, its output in the log, and is alive by its identity; one
whose id now belongs to another process is not alive and is not stopped; a stop ends it politely, or kills it when it
does not end in time; a missing program is refused with the host's words; file facts and a port's listener are read.

### Task 2: The WSL host

**Files:** `clank/components/runtime/hosts/wsl.py`; `tests/fixtures/wsl/2.7.11/program.json` (recorded on this machine);
tests `tests/components/runtime/test_wsl_host.py`.

**Interfaces:** `WslHost(run, distro)`; its scripts (start, identify, signal, file facts, listener), each one
`bash -c` script whose answer is one line of text.

**Tests:** against the recording: a start answers with the engine's identity once its command line is its own; a
signal is refused for an identity that no longer matches; UTF-16 lists of distributions are read; the contract runs
both hosts.

### Task 3: The fake engine

**Files:** `tests/fakes/engine.py`; tests `tests/components/runtime/test_fake_engine.py`.

**Interfaces:** `python -m tests.fakes.engine --style kvmem|ninfer --port N [--start-seconds S] [--fail-start
oom] [--crash-after S]`: prints its style's startup lines (taken from the adapters' recordings), answers `/health`,
`/v1/models` and a short `/v1/chat/completions`, and ends on SIGTERM (or CTRL_BREAK on Windows).

**Tests:** started on the local host, it says it is ready in its style's words, answers, and stops by its identity;
told to fail, it prints its failure and ends.

### Task 4: Hosts in the runtime

**Files:** `clank/components/runtime/service.py`, `api.py`, `cli.py`; tests `tests/components/runtime/test_hosts.py`.

**Interfaces:** `Runtime.hosts()` (the built-in `local` host and each `host` record), `Runtime.host(name) -> EngineHost`;
`GET /runtime/hosts`; `clank host list`.

**Tests:** the hosts are listed with their kind and folder; a host record naming a distribution gives a WSL host.

- [x] Tasks 1-4, each test-first, each committed and pushed; CI green at the end.

## Rulings made while building

- **Setup.** As in M1.1. Cost if wrong: a weaker review.
- **Task 1.** The local host runs on any operating system, through subprocess and psutil, so the runtime's tests run
  on Windows and on Linux CI with fake engines. On Windows a process without a console cannot be asked to end, so its
  stop is the end, said as `killed`. The host keeps the handles of what it started and reaps each when it ends (no
  zombie, no warning). Every adapter now says whether it is recorded (`RECORDED`); the local host's program is the
  running system itself, so its contract runs live. Cost if wrong: none.
- **Task 2.** Each WSL script answers one line and ends well, so a failure keeps the distribution's words. Its
  recording was made against Ubuntu 24.04 by running the scripts themselves (a `sleep 600` started, checked and
  stopped; two license files read), with the log's Windows path naming the user `<you>`. Cost if wrong: none.
- **Task 3.** A launch's program is a command, not one path, so a test runs its fake engine from the real adapters'
  plans, and a later setting can put `nice` before an engine. Cost if wrong: none.
- **Task 4.** `clank host add` has its own route, which checks that WSL has the distribution before it writes the
  record; the settings' generic route would write it unchecked. Cost if wrong: none.

## Final review

A self-review of M1.2 against design 0003 §2 and §6.3, design 0001 §4.6 and the Review Focus above: each item has its
test (a reused id, a process that ignores the polite stop (Linux), a command line not yet the engine's (the WSL start
waits for it), a program that cannot start, WSL's UTF-16); the WSL host's scripts were run against the real
distribution, including a missing program and one that ends at once; CI passed on Linux, where the POSIX paths run. No
important finding. Deferred (minor): who holds an engine's port on the Windows side of WSL's forwarding is not asked
yet (M1.3, where a start needs it); a listener of another user shows its name only.
