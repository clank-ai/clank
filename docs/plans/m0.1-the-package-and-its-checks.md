# M0.1: the package and its checks: implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or
> superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.
> This plan is executed natively in the session that wrote it: the owner asked to "plan M0.1, and start building", and
> subagents are used only when the owner asks.

**Goal:** `clank --version` runs from a package built with recorded tools, and every push to GitHub runs the
repository's checks (formatting, lint, types, tests, documents, secrets, spelling) and shows a green check.

**Architecture:** A Python package, `clank`, holding only the `clank` command for now (`clank/cli/`), managed by uv.
Development tools live in `tools/` (never shipped): they generate the code map and the tests page, and check the
documents, secrets and spelling. Each check also runs as a pytest test against the repository itself
(`tests/test_repository.py`), so `pytest` alone catches what continuous integration would. One command,
`uv run python -m tools.check`, runs formatting, lint, types and tests, on a working copy and in GitHub Actions alike.

**Tech Stack:** Python 3.12+, uv 0.12.3, hatchling 1.32, click 8.5, pytest 9.1, Ruff 0.17, mypy 2.4, GitHub Actions
(actions/checkout v7.0.1, astral-sh/setup-uv v10.2.0, each pinned to its release commit).

**Spec:** [design 0002 §3.2](../design/0002-the-foundation.md#32-m0-the-skeleton) (M0.1), with
[design 0001](../design/0001-runtime-and-console.md) §7.1 (Python and the lock file), §8.4 (continuous integration) and
§8.5 (tests say what they prove).

## Global Constraints

- Python 3.12 or newer: `requires-python = ">=3.12"`; development on 3.12, the oldest supported (`.python-version`).
- Every dependency pinned in `uv.lock`; a new dependency only with a decision record (AGENTS.md).
- Every module begins with a docstring whose first line says what the module is for (AGENTS.md).
- Each test file begins with a docstring naming the design sections it verifies, written "Design 0002 §3.2", and test
  names are sentences (design 0001 §8.5).
- Tests need no GPU and no network, and never touch a real `CLANK_HOME` (design 0001 §7.7, §8.1).
- American English everywhere; nothing personal or secret in tracked files; LF line endings (AGENTS.md,
  `.gitattributes`).
- Code lines at most 120 characters (Ruff); documents wrapped at about 118.
- Every task ends with a commit pushed to `origin main`; each message ends with
  `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>` (the owner: push every step).
- On the owner's Windows machine uv is not on the PATH: it is `%APPDATA%\Python\Python314\Scripts\uv.exe`. The
  commands below write `uv`.
- Not in M0.1: checking the repository's JSON files against their schemas (design 0001 §8.4) starts in M0.2, with the
  first kinds and their generated schemas; until then there is no such file to check.

## Review Focus

1. **Windows and Linux make different files.** A generated document must be the same bytes whichever platform wrote
   it: forward slashes in paths, LF line endings. Pinned by `test_paths_use_forward_slashes_and_a_stable_order` and
   `test_writing_uses_lf_line_endings_on_every_platform` (Task 2).
2. **`clank` run outside the repository.** The version must come from the installed package, not the working folder.
   Pinned by `test_python_dash_m_clank_runs_the_command_from_any_folder` (Task 1).
3. **Files that are not UTF-8 text.** An image or an archive in the repository must be skipped by the scanners, not
   crash them; text in another encoding must still be scanned. Pinned by `test_a_file_with_a_nul_byte_is_not_text` and
   `test_text_that_is_not_utf8_is_still_read` (Task 4) and `test_files_that_are_not_text_are_skipped` (Tasks 5, 6).
4. **Links as GitHub renders them.** Anchors of headings with punctuation, "§", code or repeats, and links inside code
   blocks (including a fence inside a longer fence). Pinned by the anchor and code tests of Tasks 3 and 4.
5. **Placeholders against real values.** `C:\Users\<you>`, `~/.clank` and the repository's own home on GitHub must
   pass; real-looking keys must not; and the checks must not trip on their own patterns. Pinned by the tests of Task 5.

````markdown
# 0022. Development tools: uv, hatchling, pytest, Ruff and mypy

- Status: Accepted
- Date: 2026-10-11
- Decided by: proposed by Claude in the M0.1 plan, under the owner's instruction to "plan M0.1, and start building"
  (2026-10-11); the owner can revisit it

## Context
Design 0001 §7.1 asks for Python 3.12 or newer, in Clank's own environment, with every dependency pinned in a lock
file; §8.4 asks for tests, a lint and a type check on every push, and leaves the tools (the test runner, the linter,
the type checker, Textual's snapshot plugin) to a decision record written with the first implementation plan. Clank
runs on Windows (its clients) and in WSL or Linux (its service), so one lock must hold on both.

## Decision
| Need | Tool | Notes |
| --- | --- | --- |
| Environments, Python versions, the lock, running commands | uv | `uv.lock` pins every dependency for every platform; `.python-version` asks for 3.12, the oldest Python Clank supports |
| Building the package | hatchling | The version is read from `clank/__init__.py` |
| Tests | pytest | Asynchronous tests use AnyIO's pytest plugin, which comes with FastAPI's dependencies (from M0.2) |
| Lint and formatting | Ruff | One tool for both; lines of 120 characters |
| Types | mypy, strict | Pydantic's plugin is added with Pydantic (M0.2) |
| Snapshots of the console | pytest-textual-snapshot | Added with the console's shell (M0.5) |

Each tool enters the lock when it is first used.

## Alternatives considered
- **pip with venv and pip-tools.** Standard, but slower, with no management of Python versions, and a lock that holds
  for one platform unless one is kept per platform.
- **Poetry or PDM.** Complete, but heavier, with conventions of their own; uv also installs Python itself.
- **setuptools.** Familiar, but it needs more configuration for the same result here.
- **Black, Flake8 and isort.** Three tools where Ruff is one, and slower.
- **Pyright.** What VS Code's Pylance uses, so its findings match the editor's, but it runs on Node.js; mypy is pure
  Python and has Pydantic's plugin.
- **pytest-asyncio.** One more dependency, where AnyIO's plugin comes with FastAPI.

## Consequences
- One command prepares a working copy (`uv sync`), and every command runs through `uv run` (AGENTS.md, Commands).
- Continuous integration installs from the same lock and fails when `pyproject.toml` and `uv.lock` disagree
  (`uv sync --locked`).
- Development uses Python 3.12, so nothing newer slips in; continuous integration also runs Python 3.14, on Linux and
  Windows, for pull requests and releases.
````

`docs/decisions/0023-click-for-the-command-line.md`:

````markdown
# 0023. The `clank` command is built with click

- Status: Accepted
- Date: 2026-10-11
- Decided by: proposed by Claude in the M0.1 plan, under the owner's instruction to "plan M0.1, and start building"
  (2026-10-11); the owner can revisit it

## Context
Every action in Clank is also a command, `clank <component> <verb>` (design 0002 §2.15). Components add their own
commands, and every kind of record also gets generic commands (list, show, change) made from the kind's definition
when the program starts, as the API's generic routes are (design 0002 §2.2). Every command prints readable text, or
JSON with `--json`, and tests run commands in-process.

## Decision
The `clank` command is built with click.

## Alternatives considered
- **argparse**, in Python's standard library. No dependency, but subcommands contributed by many components, and
  commands made at run time, take much more code, and there is no in-process test runner.
- **Typer**, built on click. It reads options from type hints, which suits commands written by hand but not commands
  made from a kind's definition at run time, and it adds its own layer and dependencies.

## Consequences
- click is a runtime dependency.
- Commands are tested in-process with click's `CliRunner`.
- Each component's `cli.py` builds a click group, which `clank/cli/main.py` adds to the top-level `clank` group.
````

````python
"""Design 0002 §3.2 (M0.1): `clank --version` reports the version of the code that is running.
````

````python
"""Design 0002 §3.2 (M0.1): the code map lists every module of `clank/` and `tools/` with the first line of its

from collections.abc import Callable
from pathlib import Path

import pytest

from tools.codemap import CodeMapError, render

Write = Callable[[dict[str, str]], Path]


def test_each_module_gets_one_line_from_its_docstring(write_files: Write) -> None:
    root = write_files(
        {
            "clank/__init__.py": '"""Clank itself.\n\nMore detail that the map leaves out."""\n',
            "clank/cli/main.py": '"""The command line."""\n',
            "tools/codemap.py": '"""Writes the map."""\n',
        }
    )
    text = render(root)
    assert "| `clank/__init__.py` | Clank itself. |" in text
    assert "| `clank/cli/main.py` | The command line. |" in text
    assert "| `tools/codemap.py` | Writes the map. |" in text
    assert "More detail" not in text


def test_paths_use_forward_slashes_and_a_stable_order(write_files: Write) -> None:
    root = write_files({"clank/b.py": '"""B."""\n', "clank/a/z.py": '"""Z."""\n', "clank/a.py": '"""A."""\n'})
    rows = [line for line in render(root).splitlines() if line.startswith("| `")]

    assert "clank/bad.py" in str(caught.value)
    assert "tools/worse.py" in str(caught.value)
    assert "clank/good.py" not in str(caught.value)

def test_a_pipe_in_a_docstring_does_not_break_the_table(write_files: Write) -> None:
````

`tools/generated.py`:

````python
"""Write a generated document, or check that the copy in the repository is up to date.

Generated documents (the code map, the tests page) are committed, so they can be read on GitHub, and by a model,
without running anything. They are written with LF line endings on every platform, so a document generated on Windows
and one generated on Linux are the same file.
"""

import sys
from pathlib import Path


def write_or_check(target: Path, text: str, *, check: bool, command: str) -> int:
    """Write `text` to `target`, or with `check` only compare them; returns the exit status for the command line."""
    if check:
        current = target.read_bytes().decode("utf-8") if target.exists() else None
        if current != text:
            print(f"{target.name} is out of date: run `{command}`", file=sys.stderr)
            return 1
        return 0
    target.parent.mkdir(parents=True, exist_ok=True)
    target.write_bytes(text.encode("utf-8"))
    print(f"wrote {target.name}")
    return 0
````

`tools/codemap.py`:

````python
"""Write `docs/CODEMAP.md`: one line per module of `clank/` and `tools/`, the first line of its docstring.

A reader, a person or a local model with a small context, finds where a thing lives without opening the code. The map
is generated, never edited by hand, and a test fails when it is out of date (`tests/test_repository.py`). A module
without a docstring is an error: every module says what it is for (AGENTS.md).
"""

import ast
import sys
from pathlib import Path

from tools.generated import write_or_check

ROOTS = ("clank", "tools")
OUTPUT = Path("docs/CODEMAP.md")
COMMAND = "uv run python -m tools.codemap"
HEADER = """\
# Code map

Generated by `python -m tools.codemap` from each module's docstring; do not edit it by hand. One line per module: what
it is for. The module's docstring says why it is built the way it is.
"""


class CodeMapError(Exception):
    """Modules the code map cannot describe: without a docstring, or not valid Python."""


def modules(root: Path) -> list[Path]:
    """Every module under the code map's roots, relative to `root`, in a stable order."""
    found = [
        path.relative_to(root)
        for top in ROOTS
        for path in (root / top).rglob("*.py")
        if "__pycache__" not in path.parts
    ]
    return sorted(found, key=lambda path: path.as_posix())


def summary(root: Path, module: Path) -> str:
    """The first line of the module's docstring; raises CodeMapError when there is none."""
    name = module.as_posix()
    try:
        tree = ast.parse((root / module).read_text(encoding="utf-8"), filename=name)
    except (SyntaxError, UnicodeDecodeError) as error:
        raise CodeMapError(f"{name}: cannot be read as Python ({error})") from error
    doc = ast.get_docstring(tree)
    if not doc or not doc.strip():
        raise CodeMapError(f"{name}: has no docstring; its first line must say what the module is for")
    return doc.strip().splitlines()[0].strip()


def render(root: Path) -> str:
    """The code map of the repository at `root`; raises CodeMapError naming every module it cannot describe."""
    rows: dict[str, list[str]] = {top: [] for top in ROOTS}
    problems: list[str] = []
    for module in modules(root):
        try:
            line = summary(root, module).replace("|", "\\|")
        except CodeMapError as error:
            problems.append(str(error))
            continue
        rows[module.parts[0]].append(f"| `{module.as_posix()}` | {line} |\n")
    if problems:
        raise CodeMapError("\n".join(problems))
    parts = [HEADER]
    for top in ROOTS:
        parts.append(f"\n## {top}\n\n| Module | What it is for |\n| --- | --- |\n")
        parts.extend(rows[top])
    return "".join(parts)


def main(argv: list[str] | None = None) -> int:
    """Write the code map, or with `--check` only report whether it is up to date; returns the exit status."""
    args = sys.argv[1:] if argv is None else argv
    root = Path(__file__).resolve().parents[1]
    try:
        text = render(root)
    except CodeMapError as error:
        print(error, file=sys.stderr)
        return 1
    return write_or_check(root / OUTPUT, text, check="--check" in args, command=COMMAND)


if __name__ == "__main__":
    sys.exit(main())
````

````python
"""Read Markdown the way GitHub does, as far as the checks need: which lines are prose, and which are code.

A fenced code block opens with three or more backticks or tildes and closes with a line of the same character, at
least as long, and nothing after it; its lines and its fences are code. Indented code blocks are not recognized,
because nested list items in these documents are indented the same way.
"""

import re

OPENING = re.compile(r"^ {0,3}(`{3,}|~{3,})")
CLOSING = re.compile(r"^ {0,3}(`{3,}|~{3,})\s*$")


def prose_lines(text: str) -> list[tuple[int, str]]:
    """The lines of `text` outside fenced code blocks, with their line numbers (from 1)."""
    lines: list[tuple[int, str]] = []
    fence = ""
    for number, line in enumerate(text.splitlines(), start=1):
        if fence:
            closing = CLOSING.match(line)
            if closing and closing.group(1)[0] == fence[0] and len(closing.group(1)) >= len(fence):
                fence = ""
            continue
        if opening := OPENING.match(line):
            fence = opening.group(1)
            continue
        lines.append((number, line))
    return lines
````

`tools/testspage.py`:

````python
"""Write `docs/TESTS.md`: each section of each design, with the test files that hold it to its word.

Each test file begins with a docstring naming the design sections it verifies, such as "Design 0002 §3.2" (design 0001
§8.5). This module reads those docstrings and the designs' numbered headings, so the page shows which sections have
tests and which have none yet. A test file that names no section, or names a section that no design has, is an error,
so the references stay true when a design changes.
"""

import ast
import re
import sys
from dataclasses import dataclass, field
from pathlib import Path

from tools.generated import write_or_check
from tools.markdown import prose_lines

OUTPUT = Path("docs/TESTS.md")
COMMAND = "uv run python -m tools.testspage"
REFERENCE = re.compile(r"design (\d{4}) §(\d+(?:\.\d+)*)", re.IGNORECASE)
TITLE = re.compile(r"^# Design (\d{4}): (.+)$")
HEADING = re.compile(r"^#{2,3} (\d+(?:\.\d+)?)\.? (.+)$")
HEADER = """\
# Tests

Generated by `python -m tools.testspage` from the tests' docstrings and the designs' headings; do not edit it by hand.
Each test file begins with a docstring naming the design sections it verifies (design 0001 §8.5).
"""


class PageError(Exception):
    """Test files the page cannot place: naming no design section, or a section that does not exist."""


@dataclass
class Section:
    """A numbered section of a design document, and the test files that name it."""

    design: str
    number: str
    title: str
    files: list[str] = field(default_factory=list)


@dataclass
class FileOfTests:
    """A test file: what its docstring says it proves, the sections it names, and its tests' names as sentences."""

    path: str
    summary: str
    references: list[tuple[str, str]]
    tests: list[str]


def designs(root: Path) -> dict[str, tuple[str, list[Section]]]:
    """Each design's title and numbered sections, in document order, keyed by the design's number."""
    found: dict[str, tuple[str, list[Section]]] = {}
    for path in sorted((root / "docs" / "design").glob("[0-9][0-9][0-9][0-9]-*.md")):
        design = path.name[:4]
        title = path.stem
        sections: list[Section] = []
        for _, line in prose_lines(path.read_text(encoding="utf-8")):
            if match := TITLE.match(line):
                title = match.group(2)
            elif match := HEADING.match(line):
                sections.append(Section(design, match.group(1), match.group(2).strip()))
        found[design] = (title, sections)
    return found


def sentence(name: str) -> str:
    """A test's name as the sentence it is: `test_a_switch_returns` becomes "a switch returns"."""
    return name.removeprefix("test_").replace("_", " ")


def files_of_tests(root: Path) -> list[FileOfTests]:
    """Every test file under `tests/`, with the sections its docstring names and its tests' names."""
    found: list[FileOfTests] = []
    for path in sorted((root / "tests").rglob("test_*.py"), key=lambda path: path.as_posix()):
        name = path.relative_to(root).as_posix()
        tree = ast.parse(path.read_text(encoding="utf-8"), filename=name)
        doc = ast.get_docstring(tree) or ""
        summary = " ".join(doc.split("\n\n")[0].split())
        references = [(match.group(1), match.group(2)) for match in REFERENCE.finditer(doc)]
        found.append(FileOfTests(name, summary, references, [sentence(test) for test in _test_names(tree)]))
    return found


def _test_names(tree: ast.Module) -> list[str]:
    """The names of a module's tests: its `test` functions, and those of its `Test` classes."""
    names: list[str] = []
    for node in tree.body:
        if isinstance(node, ast.FunctionDef | ast.AsyncFunctionDef) and node.name.startswith("test"):
            names.append(node.name)
        elif isinstance(node, ast.ClassDef) and node.name.startswith("Test"):
            names.extend(
                child.name
                for child in node.body
                if isinstance(child, ast.FunctionDef | ast.AsyncFunctionDef) and child.name.startswith("test")
            )
    return names


def _has_subsections(section: Section, sections: list[Section]) -> bool:
    return any(other.number.startswith(section.number + ".") for other in sections)


def render(root: Path) -> str:
    """The tests page of the repository at `root`; raises PageError naming every test file it cannot place."""
    known = designs(root)
    index = {(design, section.number): section for design, (_, sections) in known.items() for section in sections}
    files = files_of_tests(root)
    problems: list[str] = []
    for entry in files:
        if not entry.references:
            problems.append(f'{entry.path}: its docstring names no design section (as in "Design 0002 §3.2")')
        for design, number in entry.references:
            section = index.get((design, number))
            if section is None:
                problems.append(f"{entry.path}: names design {design} §{number}, which does not exist")
            elif entry.path not in section.files:
                section.files.append(entry.path)
    if problems:
        raise PageError("\n".join(problems))
    counts = {entry.path: len(entry.tests) for entry in files}
    leaves = [s for _, sections in known.values() for s in sections if not _has_subsections(s, sections)]
    covered = sum(1 for section in leaves if section.files)
    out = [
        HEADER,
        f"\n**{covered} of {len(leaves)} design sections have tests.** "
        "A section with subsections is covered through them.\n",
    ]
    for design, (title, sections) in known.items():
        out.append(f"\n## Design {design}: {title}\n\n| § | Section | Tests |\n| --- | --- | --- |\n")
        for section in sections:
            if section.files:
                cell = ", ".join(f"`{path}` ({counts[path]})" for path in section.files)
            elif _has_subsections(section, sections):
                cell = "see its subsections"
            else:
                cell = "none yet"
            name = section.title.replace("|", "\\|")
            out.append(f"| {section.number} | {name} | {cell} |\n")
    out.append("\n## Test files\n")
    for entry in files:
        out.append(f"\n### `{entry.path}`\n\n{entry.summary}\n\n")
        out.extend(f"- {test}\n" for test in entry.tests)
    return "".join(out)


def main(argv: list[str] | None = None) -> int:
    """Write the tests page, or with `--check` only report whether it is up to date; returns the exit status."""
    args = sys.argv[1:] if argv is None else argv
    root = Path(__file__).resolve().parents[1]
    try:
        text = render(root)
    except PageError as error:
        print(error, file=sys.stderr)
        return 1
    return write_or_check(root / OUTPUT, text, check="--check" in args, command=COMMAND)


if __name__ == "__main__":
    sys.exit(main())
````

````python
"""The repository's files as the checks see them: what git tracks or would track, read as text when they are text.

Asking git for the list means a check sees exactly what a commit would hold (never `.venv/` or caches), including a new
file before it is committed.
"""

import subprocess
from pathlib import Path


def repository_files(root: Path) -> list[Path]:
    """Every file git tracks, or would track, under `root`, relative to it, in a stable order."""
    listed = subprocess.run(
        ["git", "ls-files", "--cached", "--others", "--exclude-standard", "-z"],
        cwd=root,
        capture_output=True,
        check=True,
    ).stdout.decode("utf-8")
    names = {name for name in listed.split("\0") if name and (root / name).is_file()}
    return sorted((Path(name) for name in names), key=lambda path: path.as_posix())


def read_text(path: Path) -> str | None:
    """The file's text, or None when it is not text (a NUL byte near its start, as in images and archives)."""
    data = path.read_bytes()
    if b"\0" in data[:8192]:
        return None
    return data.decode("utf-8", errors="replace")
````

`tools/check_docs.py`:

````python
"""Check the documents: every link resolves, every decision, design and plan is in its index, and every design
section has a status (design 0001 §8.4).

Links are checked the way GitHub shows them: a link to a heading uses GitHub's anchor for it (lowercase, punctuation
removed, spaces made hyphens, a number added to a repeated heading), and text inside code is not a link. Only links
within the repository are checked; outside links would need the network, which checks never use.
"""

import re
import sys
import unicodedata
from pathlib import Path
from urllib.parse import unquote

from tools.files import repository_files
from tools.markdown import prose_lines

HEADING = re.compile(r"^ {0,3}#{1,6} +(.+?)(?: +#+)? *$")
CODE_SPAN = re.compile(r"(`+)(.+?)\1")
LINK_TEXT = re.compile(r"\[([^\]]*)\]\([^)]*\)")
LINK = re.compile(r"!?\[(?:[^\]\\]|\\.)*\]\(\s*<?([^)\s>]+)>?(?:\s+\"[^\"]*\")?\s*\)")
DEFINITION = re.compile(r"^ {0,3}\[[^\]]+\]:\s*<?([^\s>]+)>?")
OUTSIDE = re.compile(r"^[a-z][a-z0-9+.-]*:", re.IGNORECASE)
NUMBERED = re.compile(r"^(\d{4})-.+\.md$")
SECTION = re.compile(r"^## (\d+)\. ")
# Each indexed folder, and whether its documents are numbered.
INDEXES = {"docs/decisions": True, "docs/design": True, "docs/plans": False}


def slug(heading: str) -> str:
    """GitHub's anchor for a heading: lowercase, only letters, digits, hyphens and underscores kept, spaces made
    hyphens."""
    text = LINK_TEXT.sub(r"\1", CODE_SPAN.sub(r"\2", heading))
    kept = "".join(char for char in text.lower() if char in "-_ " or unicodedata.category(char)[0] in "LNM")
    return kept.replace(" ", "-")


def anchors(text: str) -> set[str]:
    """Every anchor GitHub gives the headings of a Markdown text, a repeated heading numbered as GitHub numbers it."""
    seen: dict[str, int] = {}
    found: set[str] = set()
    for _, line in prose_lines(text):
        if match := HEADING.match(line):
            base = slug(match.group(1))
            count = seen.get(base, 0)
            seen[base] = count + 1
            found.add(base if count == 0 else f"{base}-{count}")
    return found


def links(text: str) -> list[str]:
    """Every link target in a Markdown text, outside code."""
    prose = CODE_SPAN.sub("", "\n".join(line for _, line in prose_lines(text)))
    found = [match.group(1) for match in LINK.finditer(prose)]
    found += [match.group(1) for line in prose.splitlines() if (match := DEFINITION.match(line))]
    return found


def broken_links(root: Path, files: list[Path]) -> list[str]:
    """Each link within the repository to a file or a heading that does not exist."""
    problems: list[str] = []
    headings: dict[Path, set[str]] = {}
    top = root.resolve()
    for doc in (file for file in files if file.suffix == ".md"):
        for target in links((root / doc).read_text(encoding="utf-8")):
            if OUTSIDE.match(target):
                continue
            path, _, anchor = target.partition("#")
            dest = ((root / doc).parent / unquote(path)).resolve() if path else (root / doc).resolve()
            where = f"{doc.as_posix()}: links to {target}"
            if not dest.is_relative_to(top):
                problems.append(f"{where}, which is outside the repository")
            elif not dest.exists():
                problems.append(f"{where}, which does not exist")
            elif anchor and dest.suffix == ".md":
                if dest not in headings:
                    headings[dest] = anchors(dest.read_text(encoding="utf-8"))
                if unquote(anchor) not in headings[dest]:
                    problems.append(f"{where}, but that heading does not exist")
    return problems


def unindexed(root: Path, files: list[Path]) -> list[str]:
    """Each decision, design or plan missing from its folder's index, and each gap or repeat in the numbers."""
    problems: list[str] = []
    for folder, numbered in INDEXES.items():
        members = [f for f in files if f.parent.as_posix() == folder and f.suffix == ".md" and f.name != "README.md"]
        if not members:
            continue
        index = root / folder / "README.md"
        targets = links(index.read_text(encoding="utf-8")) if index.exists() else []
        listed = {target.partition("#")[0] for target in targets}
        problems += [
            f"{folder}/README.md: does not list {member.name}" for member in members if member.name not in listed
        ]
        if not numbered:
            continue
        problems += [f"{folder}/{m.name}: is not named NNNN-title.md" for m in members if not NUMBERED.match(m.name)]
        numbers = sorted(int(match.group(1)) for m in members if (match := NUMBERED.match(m.name)))
        missing = sorted(set(range(1, max(numbers, default=0) + 1)) - set(numbers))
        repeated = sorted({n for n in numbers if numbers.count(n) > 1})
        if missing or repeated:
            parts = [f"missing {', '.join(f'{n:04d}' for n in missing)}"] if missing else []
            parts += [f"repeated {', '.join(f'{n:04d}' for n in repeated)}"] if repeated else []
            problems.append(f"{folder}: numbers must run from 0001 without gaps or repeats; {'; '.join(parts)}")
    return problems


def _sections_table(lines: list[str]) -> dict[str, str]:
    """The rows of the table under the "## Sections" heading: each section's number, and its status."""
    rows: dict[str, str] = {}
    inside = False
    for line in lines:
        if line.startswith("## "):
            inside = line.strip() == "## Sections"
        elif inside and line.startswith("|"):
            cells = [cell.strip() for cell in line.strip().strip("|").split("|")]
            if len(cells) >= 3 and cells[0].isdigit():
                rows[cells[0]] = cells[-1]
    return rows


def sections_without_status(root: Path, files: list[Path]) -> list[str]:
    """Each design section missing from its document's Sections table, or listed there without a status."""
    problems: list[str] = []
    for doc in files:
        if doc.parent.as_posix() != "docs/design" or not NUMBERED.match(doc.name):
            continue
        lines = [line for _, line in prose_lines((root / doc).read_text(encoding="utf-8"))]
        headings = [match.group(1) for line in lines if (match := SECTION.match(line))]
        table = _sections_table(lines)
        name = doc.as_posix()
        for number in headings:
            if number not in table:
                problems.append(f"{name}: section {number} is missing from its Sections table")
            elif not table[number]:
                problems.append(f"{name}: section {number} has no status in its Sections table")
        problems += [
            f"{name}: its Sections table lists section {n}, which has no heading" for n in table if n not in headings
        ]
    return problems


def problems(root: Path, files: list[Path]) -> list[str]:
    """Every problem in the documents among `files` (paths relative to `root`)."""
    return broken_links(root, files) + unindexed(root, files) + sections_without_status(root, files)


def main() -> int:
    """Print every problem in the repository's documents; returns 1 when there is any."""
    root = Path(__file__).resolve().parents[1]
    found = problems(root, repository_files(root))
    for problem in found:
        print(problem, file=sys.stderr)
    return 1 if found else 0


if __name__ == "__main__":
    sys.exit(main())
````

`tools/check_secrets.py`:

````python
"""Refuse anything in the repository that looks like a key, a token, a home folder or a machine's identity (design
0001 §8.4; AGENTS.md: nothing personal or secret in the repository).

The patterns cover the common kinds of keys and tokens, paths into a user's home folder on Windows, macOS and Linux,
GPU identifiers and network hardware addresses, and the names of the user and the computer running the check. Those
names are skipped when they are generic (as on a CI machine), and a mention of the repository's own home on GitHub
(`<owner>/Clank`) is not personal. A file that is not text is skipped. A finding names its file, line and kind, never
the value, so that a secret is not copied into a log.
"""

import getpass
import re
import socket
import sys
from dataclasses import dataclass
from pathlib import Path

from tools.files import read_text, repository_files

PATTERNS = {
    "a private key": r"-----BEGIN [A-Z ]*PRIVATE KEY-----",
    "a GitHub token": r"\b(?:gh[pousr]_[A-Za-z0-9]{36,}|github_pat_[A-Za-z0-9_]{60,})",
    "an API key (sk-...)": r"\bsk-(?:ant-|proj-)?[A-Za-z0-9_-]{20,}",
    "an AWS access key": r"\bAKIA[0-9A-Z]{16}\b",
    "a Google API key": r"\bAIza[0-9A-Za-z_-]{35}",
    "a Hugging Face token": r"\bhf_[A-Za-z0-9]{30,}",
    "a Slack token": r"\bxox[abposr]-[A-Za-z0-9-]{10,}",
    "a Windows home folder": r"\b[A-Za-z]:[\\/]+Users[\\/]+(?!(?:Public|Default)\b|<)[^\\/\s<>\"'`|*?]+",
    "a macOS home folder": r"(?<![\w.~])/Users/(?!Shared\b|<)[A-Za-z0-9._-]+",
    "a Linux home folder": r"(?<![\w.~])/home/(?!<)[a-z_][a-z0-9_-]*",
    "a GPU identifier": r"\bGPU-[0-9a-fA-F]{8}-(?:[0-9a-fA-F]{4}-){3}[0-9a-fA-F]{12}\b",
    "a network hardware address": r"\b(?:[0-9A-Fa-f]{2}:){5}[0-9A-Fa-f]{2}\b",
}
# Names that identify no one: the users and machines of CI services, containers and editors.
GENERIC_NAMES = {
    "admin",
    "administrator",
    "codespace",
    "docker",
    "github",
    "localhost",
    "root",
    "runner",
    "runneradmin",
    "ubuntu",
    "user",
    "vscode",
}


@dataclass(frozen=True)
class Finding:
    """Something that looks secret or personal: where it is and what it looks like, never its value."""

    path: str
    line: int
    kind: str

    def __str__(self) -> str:
        return f"{self.path}:{self.line}: looks like {self.kind}"


def patterns(user: str | None, host: str | None, repository: str) -> dict[str, re.Pattern[str]]:
    """The patterns to look for, with the names of the user and the computer when they are not generic.

    A name followed by `/<repository>` is the repository's own home on GitHub, which is public, not personal.
    """
    compiled = {kind: re.compile(pattern) for kind, pattern in PATTERNS.items()}
    for kind, name in (("the user's name", user), ("this computer's name", host)):
        if name and len(name) >= 3 and name.lower() not in GENERIC_NAMES:
            home = re.escape("/" + repository)
            compiled[kind] = re.compile(rf"(?<![\w-]){re.escape(name)}(?![\w-])(?!{home}\b)")
    return compiled


def local_patterns(root: Path) -> dict[str, re.Pattern[str]]:
    """The patterns for the computer running the check, its user's name and its own name included."""
    try:
        user: str | None = getpass.getuser()
    except (OSError, KeyError, ImportError):
        user = None
    return patterns(user, socket.gethostname(), root.name)


def scan_text(path: str, text: str, compiled: dict[str, re.Pattern[str]]) -> list[Finding]:
    """The findings in one file's text."""
    return [
        Finding(path, number, kind)
        for number, line in enumerate(text.splitlines(), start=1)
        for kind, pattern in compiled.items()
        if pattern.search(line)
    ]


def scan(root: Path, files: list[Path], compiled: dict[str, re.Pattern[str]]) -> list[Finding]:
    """The findings in every text file of the list; files that are not text are skipped."""
    findings: list[Finding] = []
    for file in files:
        text = read_text(root / file)
        if text is not None:
            findings.extend(scan_text(file.as_posix(), text, compiled))
    return findings


def main() -> int:
    """Print every finding in the repository; returns 1 when there is any."""
    root = Path(__file__).resolve().parents[1]
    findings = scan(root, repository_files(root), local_patterns(root))
    for finding in findings:
        print(finding, file=sys.stderr)
    return 1 if findings else 0


if __name__ == "__main__":
    sys.exit(main())
````

````python
@dataclass(frozen=True)
class Finding:
    """A British spelling: where it is, the word as written, and its American form."""

    path: str
    line: int
    word: str

    def __str__(self) -> str:
        return f"{self.path}:{self.line}: {self.word} -> {AMERICAN[self.word.lower()]}"


def scan_text(path: str, text: str) -> list[Finding]:
    """The British spellings in one file's text; Markdown code blocks and lines marked `spelling: keep` are skipped."""
    lines = prose_lines(text) if path.endswith(".md") else list(enumerate(text.splitlines(), start=1))
    return [
        Finding(path, number, match.group(1))
        for number, line in lines
        if KEEP not in line
        for match in WORD.finditer(line)
    ]


def scan(root: Path, files: list[Path]) -> list[Finding]:
    """The British spellings in every text file of the list, except this one."""
    findings: list[Finding] = []
    for file in files:
        if file.as_posix() == SELF:
            continue
        text = read_text(root / file)
        if text is not None:
            findings.extend(scan_text(file.as_posix(), text))
    return findings


def main() -> int:
    """Print every British spelling in the repository; returns 1 when there is any."""
    root = Path(__file__).resolve().parents[1]
    findings = scan(root, repository_files(root))
    for finding in findings:
        print(finding, file=sys.stderr)
    return 1 if findings else 0
````

`tools/check.py`:

````python
"""Run every check that continuous integration runs, in one command: formatting, lint, types and the tests.

`uv run python -m tools.check` runs them all and names each one that fails, so one run shows every problem. With
`--fix` it first rewrites what can be rewritten safely: the formatting, Ruff's safe fixes, the code map and the tests
page. Continuous integration runs this same module (`.github/workflows/checks.yml`), so passing here means passing
there. The tests include the repository's own checks (`tests/test_repository.py`): links, indexes, secrets, spelling.
"""

import subprocess
import sys
from collections.abc import Callable, Sequence

Runner = Callable[[Sequence[str]], int]

FIXES: list[tuple[str, list[str]]] = [
    ("formatting", [sys.executable, "-m", "ruff", "format", "."]),
    ("safe lint fixes", [sys.executable, "-m", "ruff", "check", "--fix", "."]),
    ("code map", [sys.executable, "-m", "tools.codemap"]),
    ("tests page", [sys.executable, "-m", "tools.testspage"]),
]
CHECKS: list[tuple[str, list[str]]] = [
    ("formatting", [sys.executable, "-m", "ruff", "format", "--check", "."]),
    ("lint", [sys.executable, "-m", "ruff", "check", "."]),
    ("types", [sys.executable, "-m", "mypy"]),
    ("tests", [sys.executable, "-m", "pytest", "-q"]),
]


def run(command: Sequence[str]) -> int:
    """Run one command, its output going straight to the terminal; returns its exit status."""
    return subprocess.run(list(command), check=False).returncode


def main(argv: Sequence[str] | None = None, runner: Runner = run) -> int:
    """Run the fixes (with `--fix`), then every check; returns 1 when any of them failed."""
    args = list(sys.argv[1:] if argv is None else argv)
    steps = (FIXES if "--fix" in args else []) + CHECKS
    failed: list[str] = []
    for name, command in steps:
        print(f"== {name}", flush=True)
        if runner(command) != 0:
            failed.append(name)
    print(f"== failed: {', '.join(failed)}" if failed else "== every check passed", flush=True)
    return 1 if failed else 0


if __name__ == "__main__":
    sys.exit(main())
````
