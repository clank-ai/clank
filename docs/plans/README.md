One implementation plan per milestone step, written after its design is approved and before any code: the files it
creates or changes, then small tasks, each starting with a failing test, each ending in a commit pushed to GitHub. A
plan says what was done as it is done (its checkboxes), so anyone can see where the work stands and pick it up.
